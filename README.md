## 🚀 About

**NyansLostInSpace** is a Java application that brings the whimsical charm of Nyan Cat directly to your desktop. Designed with simplicity and fun in mind, this project offers a delightful experience for fans and developers alike.

## 🛠️ Features

- 🐱 Animated Nyan Cat overlay on your desktop
- 🎵 Looping background music for an immersive experience
- ⚙️ Lightweight and easy to run on most systems

## 📦 Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Daxxtropezz/NyansLostInSpace.git
   ```

2. **Navigate to the project directory:**
   ```bash
   cd NyansLostInSpace
   ```

3. **Build the project using NetBeans or your preferred Java IDE.**

4. **Run the application:**
   ```bash
   java -jar dist/NyansLostInSpace.jar
   ```

## 🧰 Built With

- [Java](https://www.java.com/) - Core programming language
- [NetBeans](https://netbeans.apache.org/) - Integrated Development Environment (IDE)
