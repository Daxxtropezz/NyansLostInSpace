# Security Policy

## Supported Versions

The table below shows which versions of **NyansLostInSpace** are currently supported with security updates:

| Version  | Supported          |
| -------- | ------------------ |
| 1.0.x    | :white_check_mark: |
| < 1.0    | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability in **NyansLostInSpace**, please report it responsibly.

- Open an issue on the [GitHub repository](https://github.com/Daxxtropezz/NyansLostInSpace/issues) and label it `security`.
- Avoid sharing sensitive details publicly. If needed, request a secure channel for disclosure.
- Expect a response within 5 business days.
- Once confirmed, fixes will be released and documented as part of a version update.

Thank you for helping keep this project safe!
